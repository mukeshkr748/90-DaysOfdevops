# Day 73 – Introduction to Observability and Prometheus

## 1. What is Observability?

Observability means understanding what is happening inside a system by using the data generated by that system.

### Three Pillars of Observability

1. Metrics
   - Numerical measurements collected over time.
   - Example: CPU usage, memory usage, HTTP requests.
   - Tools: Prometheus, CloudWatch, Datadog.

2. Logs
   - Records of events generated by applications and systems.
   - Example: Error messages and application events.
   - Tools: Loki, ELK, Fluentd.

3. Traces
   - Shows the journey of a request through different services.
   - Tools: OpenTelemetry, Jaeger, Zipkin.

5. Basic PromQL Queries
Check Prometheus target
curl -s 'http://localhost:9090/api/v1/query?query=up'

Result showed:

up = 1

This means the Prometheus target is available.

Check Memory Usage
curl -s 'http://localhost:9090/api/v1/query?query=process_resident_memory_bytes'

This shows the current memory usage of the Prometheus process.

Check HTTP Requests
curl -s 'http://localhost:9090/api/v1/query?query=prometheus_http_requests_total'

This shows the total HTTP requests handled by Prometheus.

Filter GET Requests
curl -s 'http://localhost:9090/api/v1/query?query=prometheus_http_requests_total{method="GET"}'

This filters HTTP requests using the GET method.

6. Counter vs Gauge
Counter

A Counter represents a value that normally only increases.

Example:

prometheus_http_requests_total

It represents the total number of HTTP requests.

Gauge

A Gauge represents a value that can increase or decrease.

Example:

process_resident_memory_bytes

It represents the current memory usage.
